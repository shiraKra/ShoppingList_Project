# 🛒 פרויקט ניהול רשימת קניות - הכנה לפרקטיקום

פרויקט Full-Stack הממומש בארכיטקטורת שלוש שכבות: **Angular**, **.NET Web API**, ו-**SQL Server**.

## 📝 נושא הפרויקט: ניהול רשימת קניות
המערכת מאפשרת למשתמש לנהל רשימת מוצרים לקנייה, לשייך אותם לקטגוריות ולעקוב אחר סטטוס הביצוע (טרם נקנה/בעגלה/בוצע).

## 🏗 ארכיטקטורה ומבנה המערכת
המערכת בנויה כך שצד השרת (API) משמש כ"צינור" (Pipe) בלבד בין הלקוח למסד הנתונים:
* **שכבת הלקוח (Angular):** מכילה Service מרכזי אחד המבצע את כל הקריאות ל-Endpoint יחיד בשרת (`POST /api/exec`).
* **שכבת השרת (.NET API):** מקבלת בקשה גנרית הכוללת את שם הפרוצדורה ופרמטרים בפורמט JSON, ומנתבת אותה להרצה ב-SQL Server.
* **שכבת הנתונים (SQL Server):** כל הלוגיקה העסקית ממומשת בתוך **Stored Procedures**. אין שאילתות SQL ישירות בקוד השרת.

## 🗄 מבנה מסד הנתונים
המסד כולל 3 טבלאות עם קשרי גומלין (Foreign Keys):
1. **ShoppingItems (טבלה ראשית):** מוצרים, תיאור, מזהה קטגוריה, מזהה סטטוס ותאריך יצירה.
2. **Categories (טבלת עזר):** ניהול קטגוריות המוצרים (חלב וביצים, ירקות ופירות, מאפייה וכו').
3. **Statuses (טבלת עזר):** ניהול סטטוסי הקנייה (טרם נקנה, בעגלה, בוצע).

## ⚙️ Stored Procedures שמומשו (CRUD & Search)
בפרויקט מומשו הפרוצדורות הבאות כנדרש:
* `sp_AddItem`: הוספת מוצר חדש לטבלה הראשית.
* `sp_GetAllItems`: שליפת רשימת המוצרים הכוללת JOIN לקבלת שמות קטגוריה וסטטוס.
* `sp_GetItemById`: שליפת רשומה לפי מזהה לצורך הצגת פרטים.
* `sp_UpdateItem`: עדכון רשומה קיימת בטבלה הראשית.
* `sp_SearchItems`: חיפוש טקסט חופשי על שם המוצר.
* `sp_ToggleItemStatus`: פעולה נוספת לשינוי סטטוס המוצר (Toggle).
* `sp_DeleteItem`: מחיקת מוצר מהרשימה.
* `sp_GetSummary`: קבלת סיכום כמותי של המוצרים בסל.

## 🚀 הוראות הרצה
### 1. מסד נתונים (SQL Server)
* יש להריץ את קובץ ה-SQL הנמצא בתיקיית `DB` בתוך SQL Server Management Studio. הסקריפט יצור את ה-DB, הטבלאות, הפרוצדורות ונתוני הדוגמה.

### 2. צד שרת (.NET API)
* פתחי את הפרויקט ב-Visual Studio.
* עדכני את ה-Connection String בקובץ `appsettings.json` לשרת המקומי שלך.
* הריצי את הפרויקט (F5).

### 3. צד לקוח (Angular)
* פתחי טרמינל בתיקיית ה-client.
* הריצי `npm install` להתקנת הספריות.
* הריצי `ng serve` לפתיחת האפליקציה בכתובת `http://localhost:4200`.
